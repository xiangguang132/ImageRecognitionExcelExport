这是一个使用 `create-next-app` 初始化的 Next.js 项目。
开始使用
首先，运行开发服务器：
bash

编辑



npm run dev
# 或者
yarn dev
# 或者
pnpm dev
# 或者
bun dev
在浏览器中打开 http://localhost:3000 即可查看效果。
你可以通过修改 app/page.tsx 文件来开始编辑页面。当你编辑文件时，页面会自动更新。
本项目使用 `next/font` 自动优化并加载 Geist 字体，这是 Vercel 推出的一款新字体。
